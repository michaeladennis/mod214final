 # Hurricane effects on stream chemistry
 This repository contains all of the data and code necessary to recreate Figure 3 from Schaefer et al. 2000 paper. Figure 3 represents the chemistry of 4 different streams in Bisley, Puerto Rico before, during, and after Hurricane Hugo between 1988 and 1994. 


 ## 1) Data
 Data is housed in this repository, but can also be found online in EDI. To access it through the repository, navigate to the "data" folder and find four csv files. In this folder there is a README.md file detailing the contents of each.

 McDowell, W. and International Institute of Tropical Forestry(IITF), USDA Forest Service.. 2024. Chemistry of stream water from the Luquillo Mountains ver 4923064. Environmental Data Initiative. https://doi.org/10.6073/pasta/f31349bebdc304f758718f4798d25458 (Accessed 2026-08-25).

 ## 2) Code
 Code to perform the analyses is within the file titled "1_clean_data.R".  This file contains the necessary scripts to create the stream chemsitry data. To create the figure, see the file "paper.qmd" located within the "docs" folder of this repository.

 Current contributors of this repository include Michaela Dennis, Sophia Soriano, and Gitanjali Sharma.
