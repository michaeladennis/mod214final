# Data
All data necessary for this figure is located within the knb-lter .zip file.
After opening the .zip file, we will only need four of the listed CSVs.

## QuebradaCuenca1-Bisley.csv
This file contains the data for the stream denoted as "BQ1" in figure 3. This dataset contains the dates of each sample, sample IDs, and various ion concentrations within the Quebrada Cuenca 1 river.
Column names include 
* Sample_Date
* NH4-N
* NO3
* Mg
* K
* Ca
